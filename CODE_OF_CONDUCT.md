# Code of Conduct

This project follows the spirit of the Contributor Covenant, version 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful, welcoming and constructive. Harassment, personal attacks, discrimination and publishing others' private information are not acceptable.

## Enforcement

Maintainers may remove, edit or reject contributions that violate this code and may restrict participation. Report concerns to **frankoduro1912@gmail.com**. Reports are handled privately and in good faith.
