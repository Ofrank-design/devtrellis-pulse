# Support

- **Bugs:** open an issue with the Pulse version, OS, Python version, Git version and a redacted `pulse doctor` output.
- **Questions:** open a discussion or issue labelled `question`.
- **Supported:** Python 3.11+, Linux and macOS.
- **Not supported:** Windows (untested), running Pulse as root, third party task plugins, guaranteed commit counts.
- **Security reports:** see `SECURITY.md`, never a public issue.
