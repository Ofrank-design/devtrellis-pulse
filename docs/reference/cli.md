# Command reference

<!-- pulse:cli-reference:start -->
| Command | Purpose | Writes repository files? |
|---|---|---|
| `pulse init` | Create starter config | Config only |
| `pulse inspect` | Inspect repository | No |
| `pulse plan` | Preview eligible tasks | No |
| `pulse run` | Execute approved tasks | Possibly |
| `pulse report` | Render run report | No |
| `pulse history` | List previous runs | No |
| `pulse tasks` | List task registry | No |
| `pulse schedule` | Show scheduler snippets for cron, systemd or GitHub Actions | No |
| `pulse ledger` | Check or prune the activity ledger | Ledger only |
| `pulse validate-config` | Validate config | No |
| `pulse doctor` | Diagnose installation | No |
| `pulse version` | Print version | No |
<!-- pulse:cli-reference:end -->
