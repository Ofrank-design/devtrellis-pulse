# Task catalog

| Task | Purpose | Default |
|---|---|---|
| `documentation` | Required files, local links, code fences, headings, generated CLI reference | on |
| `repository_health` | Facts about the repository, no scores | on |
| `dependency_inventory` | Manifest counts and lockfile presence | on |
| `tests` | Runs the test commands you configure | off |
| `code_hygiene` | Runs your linters, and formatters in write mode | off |
| `activity_report` | Writes the run report into the repository | off |
